# Jayant Kurekar - Portfolio v2

Welcome to the source code for my personal portfolio website, built to showcase my projects, skills, and achievements as a Full-Stack Software Engineer building across Backend, AI, and Web3.

## 🚀 Live Demo

[Visit my portfolio](https://jayant-portfolio.vercel.app/) *(Note: replace with your actual deployed URL)*

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Custom CSS (Vanilla)
- **Icons:** [lucide-react](https://lucide.dev/)
- **Components:** GitHub Calendar for contribution graphs
- **Tooling:** ESLint

## ✨ Features

- **Modern & Responsive UI:** Designed with a sleek, minimalist aesthetic using a bento-box layout.
- **Projects Showcase:** Highlights key projects like InfrGate, ProofOS, Walnut, and Bliss.
- **Achievements & Hackathons:** Details on 15+ hackathons and grants won (Fhenix, Aleo, ETHMumbai, etc.).
- **Interactive Elements:** Smooth tab navigation and a built-in "Buy me a Coffee" payment modal supporting Crypto and UPI.
- **Live GitHub Stats:** Real-time GitHub contribution graph integration.

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites

- Node.js (v18+ recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Iam-jayant/jayant-portfolio.git
   cd jayant-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port provided in your terminal).
